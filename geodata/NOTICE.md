# Bundled Geo Data

Pure Clash distributes `GeoSite.dat`, `GeoIP.dat`, and `Country.mmdb` from
[MetaCubeX/meta-rules-dat](https://github.com/MetaCubeX/meta-rules-dat).

The exact upstream commit, file sizes, and SHA-256 digests are recorded in
`manifest.json`. The data is licensed under GPL-3.0; the upstream license is
included as `LICENSE`.
